---
title: "AssetCrunch"
description: "A CLI tool for batch optimizing game assets (textures, models) for web deployment."
tags: ["Tool", "CLI", "Node.js"]
pubDate: 2024-03-20
---

A simple CLI utility to help game developers prepare their assets for high-performance web environments.

```bash
crunch --input ./assets --output ./dist --quality high
```
